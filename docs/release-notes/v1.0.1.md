# Bogie v1.0.1 — release notes (DRAFT, not tagged)

> Draft written before the tag. Edit the PR numbers and date when it ships.

v1.0.1 fixes one bug in `bogie g job` and makes `bogie doctor` able to see
the damage that bug left behind. Nothing in the 1.0 compatibility promise
changes. v1.0.0 stays as it is: existing apps and the book pin it, so this
ships as a new tag, v1.0.1.

## What it fixes

- **`bogie g job` on an app without `--jobs`, when another file conflicts.**
  The first `g job` adds `--jobs` by merging the River changes into the app.
  If any file conflicted (a customised `README.md` is enough), v1.0.0
  stopped right there, before it wired anything. The app was left with
  `app/jobs/` but no `"worker": runWorker,` in `main.go`, so
  `<app> worker` fell through to `serve`; no `app/jobs` import in
  `app/application.go`; `jobs = false` in `bogie.toml`; and an untidied
  `go.mod`. Running `bogie g job` again did not help, because it skips
  enabling once `app/jobs/jobs.go` exists.

  Now the wiring (`main.go`, `app/application.go`, `bogie.toml`,
  `go mod tidy`) runs even when files conflicted. The command then lists the
  conflicts and exits 1, as before. If `main.go` or `app/application.go`
  itself conflicted, that file is not touched and the error names it and the
  line to add by hand. The other steps still run.

- **Half-enabled apps are detected and repaired.** When `app/jobs/jobs.go`
  exists, `bogie doctor` now checks that `main.go` has
  `"worker": runWorker,`, that `app/application.go` imports
  `<module>/app/jobs`, and that `bogie.toml` says `jobs = true`. Each failure
  names the fix. `bogie g job` makes the same check and repairs what is
  missing before it writes the job; with `--pretend` it only reports. Apps
  that are healthy, and apps without `app/jobs`, see no change.

## If v1.0.0 (or earlier) already half-enabled your app

Run `bogie g job NAME` with this version and it repairs the app. By hand:

1. In `main.go`, add `"worker": runWorker,` above `// bogie:commands`.
2. In `app/application.go`, add `"<module>/app/jobs"` to the imports.
3. In `bogie.toml`, set `jobs = true`.
4. Run `go mod tidy`, then `bogie doctor` and `bin/ci`.

Also resolve any conflict markers the first run left behind (`README.md`,
for example) before you commit.
